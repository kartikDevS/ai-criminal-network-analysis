## Purpose & Scope

HTTP client and WebSocket services interfacing with the FastAPI backend:
- `apiClient`: Axios/Fetch wrapper with JWT interceptors.
- `graphService`: Subgraph fetching and node position caching.
- `anomalyService`: Real-time alert polling and filter queries.
