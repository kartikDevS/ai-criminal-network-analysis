**Status:** PLANNED / SPECIFIED  
**Primary Owner:** System Architect  
**Branch:** `architect`

---

## Purpose & Scope

Standardized library of parameterized Cypher queries for investigative workflows:
- Multi-hop traversal (e.g. Find all accounts reachable from Person X within 3 hops).
- Shared infrastructure discovery (e.g. Find all persons who have logged in via the same device or IP).
- High-velocity transaction paths and cycle detection (money mule rings).
