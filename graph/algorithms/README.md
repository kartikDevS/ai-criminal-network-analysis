## Purpose & Scope

Implementations and wrappers for graph analytical algorithms (using NetworkX and Neo4j GDS):
- **Community Detection:** Louvain / Leiden modularity optimization.
- **Centrality Metrics:** PageRank, Betweenness Centrality, Degree Centrality.
- **Shortest Paths:** Dijkstra / All-Pairs Shortest Path for fund tracking.
- **Bridge Detection:** Identification of critical connectors between disjoint clusters.
