## Purpose & Scope

FastAPI router definitions:
- `/entities`: Entity retrieval and query endpoints.
- `/graph`: Subgraph exploration and neighborhood traversal routes.
- `/anomalies`: Anomaly feed, alert triage, and risk explanation endpoints.
- `/cases`: Case management and investigative docket handlers.
