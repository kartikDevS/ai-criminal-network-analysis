## Purpose & Scope

This module generates 100% synthetic, non-PII datasets containing:
- Multi-entity relational tables (Persons, Phones, Devices, IPs, Accounts, Locations, Organizations, Cases)
- Dynamic interaction events with circadian rhythms, geographic velocity hops, and realistic shared infrastructure.
- Isolated ground-truth evaluation datasets in `data/ground_truth/`.
